# 电传打字机
> 键盘敲一个字，纸上马上写一个字。
<!-- keywords: 电传 打字机 终端 teletype 键盘 实时 换纸 -->

电传打字机在工作台左侧栏的 **电传打字机** 页。会话期间写字机只听它的：任务要等会话结束才能开始，急停随时有效。

## 开始一次会话 {#start}

1. 放好纸，在页面的 **定位** 卡片里点动，把笔（抬起状态）停在要写内容的左上角。
2. 选纸张、字高和书写速度。A4、字高 3 mm 时一页 80 列 × 58 行。
3. 点 **开始**。笔现在的位置就是这张纸的原点，第一行第一个字在它右下方（隔一个边距）。
4. 点按 **打字** 框，开始打字。

## 打字 {#typing}

- 每按一个键立刻写到纸上。灰色的字是排队中，深色的是已经写出的。
- 退格 = 字车退一格，下一个字叠着写；回车换行；Tab 跳到下一个 8 列。
- 支持中文输入法，全角标点会转成半角；字库里没有的字画成方框。

## 换纸 {#paper}

写满一页（或点 **换纸**）后，笔抬起回到原点，之后的输入先缓存。换上新纸、左上角对准原来的位置，点 **已换纸，继续**。

## 停止与结束 {#stop}

- **暂停 / 继续**：暂时停笔。
- **停止并清空队列**：没写出的字丢弃，会话保持打开。
- **结束会话**：笔抬起回到原点，机器交还给任务队列。
- 急停或报警后原点会失效：抬笔，把笔点动回本页的左上角，点 **设为原点** 再继续。

## 终端模式 {#modes}

管理员在服务端打开 `teletype.terminal_enabled` 后，页面上会多出 **终端模式**：网页里是控制盒上的命令行，纸上同步抄写整个会话。全屏程序（vim、top）在纸上只记一行。

> 终端模式是控制盒上的完整 shell，只在可信的局域网里打开。
