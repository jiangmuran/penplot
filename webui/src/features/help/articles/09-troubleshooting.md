# 故障排除
> 报警码、错误码、断线、笔压、位置偏移、WiFi、预览和实际不一致。
<!-- keywords: 故障 问题 报错 报警 ALARM error 错误码 断线 连接 串口 笔压 划纸 断线 偏移 错位 丢步 WiFi 网络 预览 不一致 解锁 -->

先看屏幕顶部的横幅，它通常已经写了该怎么做。下面按现象查。

## 连接不上 {#cannot-connect}

| 提示 | 处理 |
|---|---|
| 找不到端口 | 检查 USB 线和写字机电源；换一根能传数据的线（有的线只能充电） |
| `port_busy`（端口被占用） | 另一个程序在用串口，比如电传打字机演示：`systemctl stop teletype` |
| 连上了但没有版本号 | 波特率不对，应为 115200；或者主板还在启动，等 3 秒再连 |

## 写到一半断线 {#serial-lost}

任务会以「串口断开」结束，**原点随之失效**。

1. 检查 USB 线是否松动，写字机是否断电。
2. 重新连接，抬笔，把笔移回原来的起笔点（要写内容的左上角，纸不要动），重新设原点。
3. 在任务页点「从断点继续」，从停下的那一行接着写（建议先走边框确认位置）。

## WiFi 断开 / 网页连不上 {#wifi}

机器上正在写的任务**不受影响**，它在控制盒上运行，不依赖你的浏览器。网页会显示「连接中断，正在重连」，恢复后自动同步进度。

- 一直连不上：确认手机/电脑和控制盒在同一个 WiFi 里，地址形如 `http://<控制盒的 IP>:8080`（例如 `http://192.168.1.50:8080`）。
- 信号差：控制盒离路由器近一点。系统页能看到 WiFi 信号强度，低于 -75 dBm 容易掉线。

## 笔压不住 / 划纸 {#pen-pressure}

| 现象 | 处理 |
|---|---|
| 线断断续续、颜色淡 | 落笔不够深：落笔高度加 0.5 mm |
| 线太粗、纸被划破、纸被拖着走 | 落笔太深：减 0.5 mm；纸四角贴牢 |
| 字与字之间有拖线 | 抬笔不够高（Z0 不在抬起位置）：抬笔后重新设 Z 零点 |
| 笔头晃动、线条抖 | 笔夹没拧紧；落笔速度太快，可降低 Z 速度 |

调整方法见 [设置向导 · 认识你的笔](/welcome)。

## 位置偏移 / 字写歪 {#offset}

- **整体偏移**：笔没停在要写内容的左上角。重新设原点，先走边框。
- **越写越偏（丢步）**：速度太快或皮带松。降低书写速度（设置 → 机器配置），检查皮带张紧和滑轨有没有异物。
- **报警后位置全乱**：ALARM 之后坐标作废，必须重新设原点。

## 预览和实际不一致 {#preview-mismatch}

1. 预览按「要写内容的左上角 = 原点」显示（创作台里可改成纸角）。笔停的位置不对，位置就整体不对。
2. 字体缺字时，预览和纸上都是方框，看预览上方的缺字提示。
3. 方向反了或镜像：检查 设置 → 机器配置 的原点角和轴反向。
4. 尺寸不对（比如方块不是 20 mm）：固件的每毫米步数（`$100`、`$101`）不对，在调试页的固件参数里修正。

## ALARM 报警码 {#alarm}

报警时机器会锁住，所有运动停止。处理完原因后点 **解锁**（相当于 `$X`），然后**重新设原点**。

| 代码 | 含义 | 处理 |
|---|---|---|
| ALARM:1 | 硬限位触发 | 本机没有限位开关，多为接线干扰。检查线路后解锁 |
| ALARM:2 | 软限位：目标超出行程 | 本机默认不用软限位；如开了 `$20`，缩小内容或挪原点 |
| ALARM:3 | 运动中复位，坐标丢失 | 抬笔，把笔移回起笔点重新设原点 |
| ALARM:4 | 探针初始状态错误 | 写字机用不到探针，检查是否误发了 G38 |
| ALARM:5 | 探针未触发 | 同上 |
| ALARM:6 | 回零失败：被复位打断 | 本机不使用回零，不要执行 `$H` |
| ALARM:7 | 回零失败：安全门打开 | 同上 |
| ALARM:8 | 回零失败：未能离开限位 | 同上 |
| ALARM:9 | 回零失败：找不到限位开关 | 同上；如误开了回零，`$22=0` |
| ALARM:10 | 回零失败（部分固件：双轴回零） | 同上 |

## error 错误码 {#error}

`error:N` 表示某一行 G 代码被机器拒绝。打印时默认「遇错停止」，任务页会显示出错的行。

| 代码 | 含义 |
|---|---|
| error:1 | 缺少指令字母（G、X 等） |
| error:2 | 数字格式错误 |
| error:3 | `$` 指令写错 |
| error:4 | 数值不能为负 |
| error:5 | 未启用回零，不能执行回零 |
| error:6 | 步进脉冲时间太短（< 3 µs） |
| error:7 | EEPROM 读取失败，已恢复默认参数（请检查 `$$`） |
| error:8 | 只有空闲时才能执行 `$` 指令 |
| error:9 | 报警或点动中，G 代码被锁定（先解锁） |
| error:10 | 未启用回零时不能开软限位 |
| error:11 | 一行太长（超过 80 字符） |
| error:12 | 参数超过最大步进频率 |
| error:13 | 安全门打开 |
| error:14 | 启动行或版本信息太长 |
| error:15 | 点动目标超出行程 |
| error:16 | 点动指令格式错误 |
| error:17 | 激光模式需要 PWM 输出 |
| error:20 | 不支持的 G 代码 |
| error:21 | 同一行里有同组的两个指令 |
| error:22 | 未设置进给速度（缺少 F） |
| error:23 | 指令需要整数值 |
| error:24 | 同一行两个指令都要用坐标轴 |
| error:25 | 同一个字母重复出现 |
| error:26 | 指令缺少坐标轴 |
| error:27 | 行号无效 |
| error:28 | 指令缺少必须的参数 |
| error:29 | 不支持 G59.x 坐标系 |
| error:30 | G53 只能和 G0、G1 一起用 |
| error:31 | 有坐标轴但没有指令使用它 |
| error:32 | 圆弧缺少平面内坐标 |
| error:33 | 运动目标无效 |
| error:34 | 圆弧半径无效 |
| error:35 | 圆弧缺少平面内偏移 |
| error:36 | 行里有没用到的参数 |
| error:37 | 刀长补偿轴错误 |
| error:38 | 刀号超出范围 |

自己写的 G 代码出错时，多半是 error:20 / 22 / 33。用软件生成的 G 代码一般不会出这些错误。真遇到了，请把任务页的出错行截图反馈。
