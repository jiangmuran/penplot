# 安全须知
> 用之前花一分钟看一下。
<!-- keywords: 安全 急停 注意 危险 儿童 夹手 断电 -->

## 急停 {#estop}

- 任何时候按屏幕右上角红色 **急停**，或键盘 `Ctrl/⌘ + .`，机器立刻停止。
- 急停后原点失效，需要重新设原点。
- 软件急停依赖网络。网络不稳时，**直接关写字机电源**同样安全。

## 运动时 {#motion}

- 机器运动时不要把手伸进笔架和导轨之间。
- 长头发、袖口、挂绳远离皮带和滑轨。
- 有小孩和宠物时，不要让机器无人看管地连续批量写字。

## 笔和纸 {#pen-paper}

- 落笔高度不要调得过深，笔尖可能刺破纸、损坏笔，或者把纸推走后刮伤台面。
- 不要用刀片、激光头等替代笔，本软件只针对写字笔设计。

## 网络 {#network}

- 首次使用时设置的管理员密码请妥善保管。不要把控制盒直接暴露在公网。
- API 令牌等同于密码，只给信任的脚本使用，不用了就吊销。
- 电传打字机的终端模式拥有控制盒的最高权限，只在可信网络里演示。
