# 图片描线
> 把照片、Logo、简笔画变成笔能画的线条。
<!-- keywords: 图片 照片 描线 描摹 边缘 骨架 点阵 SVG DXF logo 线稿 -->

## 三种描线方式 {#modes}

| 方式 | 适合 | 效果 |
|---|---|---|
| 边缘 | 照片、复杂图片 | 找出明暗交界，画轮廓线 |
| 骨架 | 线稿、手写签名、黑白 Logo | 取线条中心线，一笔一条 |
| 点阵 | 人像、渐变 | 用大小不一的小圈表现深浅（很慢） |

## 步骤 {#steps}

1. 把图片拖进创作台，选「描线」。
2. 先选方式，再拖「阈值」「模糊」滑块，直到预览清楚又不太乱。
3. 「最短线段」调大可以去掉碎点，「简化」调大可以减少抖动和 G 代码行数。
4. 设置宽度（毫米），放到纸上合适的位置。

## 小技巧 {#tips}

- 线条越少写得越快。一张照片描出几千条线，可能要写一个小时以上。
- 背景越干净越好。先在手机上裁剪、调高对比度再导入。
- 已经是矢量图（SVG / DXF）就直接导入，效果比描线好得多。
