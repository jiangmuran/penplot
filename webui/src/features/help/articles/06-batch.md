# 批量信件
> 用一张表格，一次写几十封信、信封或席位卡。
<!-- keywords: 批量 信件 信封 表格 CSV Excel xlsx 变量 模板 席位卡 邮件合并 -->

## 原理 {#how}

在文字里写 `{{name}}` 这样的**变量**，打印时用表格里每一行的值替换，一行生成一个任务。

## 步骤 {#steps}

1. 在 **项目与模板** 打开「信封地址」「通知函」或「席位卡」模板（也可以自己在文字里加 `{{变量名}}`）。
2. 准备表格（CSV 或 Excel），**第一行是列名**，例如：

   ```
   name,address,postcode
   李华,北京市海淀区中关村大街1号,100080
   王芳,广东省广州市天河区体育西路100号,510620
   ```

3. 在创作台点 **批量**，上传表格，把变量对应到列（同名会自动对应）。
4. 翻看每一行的预览，确认没有缺字、没有超出。
5. 点 **生成任务**。每行变成一个排队任务。

## 换纸 {#paper}

批量任务默认写完一张就暂停，等你换好纸、按「下一张」再继续。信封尺寸一致时，可以在纸桌上贴一个定位角，每次把信封推到角里，就不用每次重设原点。

如果在设置里打开「批量自动继续」，机器写完会直接写下一张，只适合连续纸或自动送纸的场合。

## 示例数据 {#sample}

系统自带两份示例表格：`addresses.csv`（收件人地址）和 `guests.csv`（宾客与桌号）。

> 表格用 UTF-8 编码保存。用 Excel 另存为 CSV 时选「CSV UTF-8」，否则中文会乱码。
