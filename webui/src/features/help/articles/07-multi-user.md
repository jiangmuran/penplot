# 多人使用与控制权
> 好几个人同时打开网页时，谁能动机器。
<!-- keywords: 多人 用户 控制权 权限 管理员 操作员 只读 占用 抢 锁 -->

## 角色 {#roles}

| 角色 | 能做什么 |
|---|---|
| 管理员 | 全部：用户、机器配置、固件参数、终端 |
| 操作员 | 控制机器、打印、编辑项目 |
| 只读观察 | 只能看状态和任务 |

管理员在 **设置 → 用户** 里添加账号。

## 控制权 {#lease}

同一时刻只能有一个人操纵机器（点动、设原点、开始打印）。第一个动手的人自动拿到**控制权**，其他人会看到「某某正在控制」，按钮变灰。

- 用完点「释放控制权」，或者关掉网页一段时间后自动释放。
- 管理员可以强制接管，对方会收到提示。
- **急停对所有人都有效**，不需要控制权。

## 同时编辑 {#editing}

项目会自动保存。两个人同时改同一个项目，后保存的人会收到「内容已被别人修改」，可以选择重新载入或另存一份。
