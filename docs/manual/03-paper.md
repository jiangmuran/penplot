# 纸张与位置
> 选纸、放纸、对准原点，以及内容写歪了怎么办。
<!-- keywords: 纸张 纸 位置 尺寸 A4 明信片 信封 贺卡 边距 方向 横向 偏移 歪 -->

## 选纸张尺寸 {#size}

在创作台点纸张名称即可切换。内置 A4、A3、16 开；系统还预置了：明信片 148×100、贺卡 A5 对折、信封 DL / C5 / 中式 5 号 / 7 号 / 3 号、便签 76×76、席位卡、名片、书签，以及「A4 小一圈 200×287」（四周留 5 mm 余量，避免写出纸边）。

自定义尺寸：**设置 → 纸张** 新建，宽高都按竖放填写；横着放的纸把方向设为「横向」。

## 放纸 {#placing}

1. 纸放在笔能到的范围内，靠近机器原点一侧。
2. 四角用美纹纸胶带固定。卡纸较硬可以只贴两角，薄纸一定贴四角。
3. 纸边尽量和机器的 X 轴平行，否则整行字会斜。

## 原点和纸的关系 {#origin}

默认情况下，原点 = **要写内容的左上角**（内容外框的左上角），笔停在哪里，内容就从哪里开始写。所以：

- 放好纸，把笔（抬起）移到纸上你想开始写的位置，点「设为原点」。
- 纸角被纸夹挡住也没关系，笔不需要去纸角。
- 想按纸角定位？在创作台右侧「原点与坐标」里选「纸张左上角」，这时要把笔停在纸角（可加向内偏移）。

一定先 [走边框](/help/glossary#frame) 再写。

## 内容写歪 / 位置不对 {#offset}

| 现象 | 原因 | 处理 |
|---|---|---|
| 整体偏移 | 笔没停在起笔点 | 把笔移到要写内容的左上角重新设原点 |
| 整行往一边斜 | 纸没放正 | 让纸边平行于 X 轴 |
| 写到一半开始错位 | 丢步（速度太快或卡住） | 降低速度，检查皮带和导轨 |
| 方向完全反了 | 原点角或轴方向设置不对 | 设置 → 机器配置 → 原点角 / 轴反向 |

更多见 [故障排除](/help/troubleshooting#offset)。
