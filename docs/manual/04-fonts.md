# 字体与缺字
> 选择字体、混排、为什么有的字变成方框。
<!-- keywords: 字体 字库 缺字 方框 □ 生僻字 TTF 导入 gfont psf 混排 手写 -->

## 选择字体 {#choose}

在 **字库** 页可以预览全部字体，输入一段文字就能看到每个字体写出来的样子。手写体普遍只收录了常用的 6000–7000 个汉字。

## 缺字是什么 {#missing}

字体里没有某个字时，这个字会被写成一个**方框**（或者跳过，可在文字属性里选）。创作台会在预览上方提示「缺 3 个字：龘 …」。

处理办法：

1. **换字体**：字库页搜索时勾选「包含这些字」，只列出能写全的字体。
2. **字体混排**：主字体写不了的字，用第二种字体补上。
3. **改字**：生僻字换成常用字，或者用拼音。
4. **符号**：全角数字（０１２）、间隔号（·）、方框（□）等很多手写体都没有，换成半角数字和普通标点。

## 导入字体 {#import}

把 `.gfont` / `.psf` 文件拖进窗口即可安装。`.ttf/.otf` 也可以，导入时选：

- **骨架**：提取笔画中线，适合黑体、圆体。
- **轮廓**：沿字的外轮廓描，会是空心双线，适合大字号标题。

字体文件有版权，导出项目时默认不打包字体。

## 大小怎么算 {#size}

文字大小按「字号（毫米）」设置。不同字体字面大小不一样：同样 10 mm，有的字体写出来 7 mm 高，有的只有 5 mm。以预览为准。
