# 快速开始
> 从开箱到写出第一张纸，大约 10 分钟。
<!-- keywords: 入门 新手 第一次 开始 上手 向导 -->

第一次使用建议直接走 [设置向导](/welcome)，它会一步步带你完成下面的事。想自己来，就照这个顺序做。

## 1. 连接写字机 {#connect}

1. 用 USB 线把写字机接到控制盒（Orange Pi）上，打开写字机电源。
2. 打开 **控制** 页，在「端口」里选 `usb-1a86_USB_Serial…`（CH340 串口），点 **连接**。
3. 状态灯变成绿色的「空闲」，就说明连上了。固件版本应显示 `1.1f`。

连不上时看 [故障排除 · 连接不上](/help/troubleshooting#cannot-connect)。

## 2. 调好笔的高度 {#pen}

本机的笔由 Z 轴步进电机带动：**Z0 = 抬笔（停放位置），Z 往正方向走 = 往下压**，默认 Z8 落笔。

- 开机前先把笔手动推到抬起的位置，这个位置就是 Z0。
- 在控制页用 Z 点动每次下探 0.5 mm，直到笔尖**刚好**碰到纸，把这个值记为「落笔高度」。
- 笔压太重会划破纸、抖线；太轻会断线。详见 [名词解释 · 抬笔/落笔](/help/glossary#pen)。

## 3. 放纸、设原点 {#origin}

本机没有限位开关，**开始写字那一刻笔所在的位置就是原点**。默认原点对应**要写内容的左上角**，不是纸角：纸夹通常把纸角挡住，笔也不需要够到纸角。

1. 用胶带或纸夹把纸固定好（纸会被笔尖带着跑）。
2. 抬笔，用方向键把笔尖移到纸上**要写内容的左上角**（第一行第一个字的左上方）。
3. 点 **设为原点**。
4. 打印前点 **走边框**，笔会抬着沿内容外框走一圈，确认不会写出纸外。

## 4. 写第一张 {#first}

1. 打开 **创作台**，或者在 **项目与模板** 里挑一个模板（生日贺卡、明信片、信封……）。
2. 改文字、换字体，右侧预览就是纸上的样子。
3. 点 **打印**：检查纸张和预计时间，勾选 **笔已抬起，并停在要写内容的左上角**，再点 **开始打印**。开始时会把笔现在的位置（含笔高）设为原点。
4. 写的过程中可以随时 **暂停**；出意外按 **急停**（`Ctrl/⌘ + .`）。

> 小提示：第一次先写一张便宜的纸，确认位置和笔压，再换正式的卡纸。
