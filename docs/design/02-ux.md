# 02 · UX 与视觉设计规范（PenPlot Workbench）

> Web 工作台，运行于 Orange Pi，局域网访问；桌面浏览器 / iPad / 手机。界面语言：简体中文。
> 风格：Apple HIG（macOS / iPadOS 观感）。栈：React 18 + TS + Vite、Tailwind、Radix（shadcn 风格）、
> lucide-react、TanStack Query、Zustand、react-router。本文只定义交互与视觉，不含实现代码。

后端能力对照：`PageInfo`（纸张/边距/行数/字号/行距/基线/旋转/`fontPath`+`fontChance` 混排）、`FontsSet`
（randomY/FontSize/Space/Rotate/XScale/YScale、simple RDP）、`write`（align L/C/R/D、seed、optimize、work）、
`img edge|skeleton|dots`、`gcode2svg`、`MachineConfig`（Grbl/Marlin/Ebb/K_AT + Settings + Axes + Advanced）、
`Sender`（start/pause/stop、progress、errors、alarm、single_step）、`MachineController`（jog、set_pen、
set_zero、go_home、home_axes、unlock、sleep）。
**需后端新增**：Profile 的机器行程 `workArea {w,h}`（现仅 CLI `--work`）、项目/模板存储、DXF/PDF 导入导出、
走边框命令、CSV 批量渲染、单任务参数覆盖（overrides）。

- 侧边栏：半透明材质 + 模糊；条目 32px（`pointer:fine`）/ 44px（`pointer:coarse`）；选中 = 圆角 6 `accent/15%` 底 + accent 图标；任务数角标为灰色胶囊。
- 工具栏结构固定：`[侧边栏切换 panel-left] 标题·文档名▾ | 页面专属控件 | 弹性空白 | 状态胶囊 | 次要图标按钮 | 主操作(每屏≤1，accent 实心) | [检查器 panel-right] | [急停]`。图标按钮均有 tooltip（含快捷键）。
- 检查器：300px（拖 260–400），顶部分段切换参数组，内容为 inset-grouped 表单（卡片圆角 10，行高 44，标签左 / 控件右）。

### 2.3 机器状态胶囊
工具栏中部偏右（Xcode activity 风格）；compact 并入机器条左侧。点击 → Popover：端口、波特率、固件、Profile、坐标、最近错误、[连接/断开] [打开控制]。

| 状态 | 色 | 图标 | 文案 |
|---|---|---|---|
| 服务器离线（WS 断） | gray | `wifi-off` | 设备离线 · 重连中 |
| 未连接 / 连接中 | gray | `plug-zap` / spinner | 未连接 / 连接中… |
| Idle | green | `circle-check` | 空闲 |
| Run | blue | `activity` | 运行 · 42% |
| Hold / 等待换纸 | orange | `pause-circle` | 已暂停 / 等待换纸 |
| Alarm | red | `siren` | 报警 · 需解锁 |
| 固件 error | red | `triangle-alert` | 错误 ×3 |

颜色 + 图标 + 文字并用；胶囊底 = 状态色 15%，文字用 `--on-tint-*`（≥4.5:1）；`aria-live=polite`，报警 `assertive`。

### 2.4 急停（E-Stop）
- 位置：regular 工具栏最右端（所有页面同位）；compact 机器条最右端。未连接时禁用但占位（不跳布局）。
- 外观：≥44×44（compact 48），red 实心圆角 10，`octagon-x` 白 +「急停」（compact 仅图标 + `aria-label`）；与邻近控件间距 ≥8。
- 行为：**单击立即执行、不确认**：feed hold → 软复位（GRBL `!`+`0x18`；Marlin `M112`；EBB `ES`）→ 清空队列；之后弹非模态卡片「已急停，机器需复位」[解锁并抬笔]。快捷键 Mod+`.`。
- 渲染在独立 top-layer portal，z-index 高于所有 Sheet/Dialog/遮罩。
- 与**停止**区分：停止 = Sender.stop（抬笔 + 回原点），需确认。设置›关于 提示：软件急停依赖网络，建议加装物理急停。

### 2.5 任务迷你播放器
任务运行/暂停/等待换纸时全局可见（任务页除外）。regular：侧边栏底部卡片；侧边栏隐藏时收进状态胶囊（显示进度环）。compact：机器条。
内容：缩略图 32 · 任务名（批量时「第 3/120 条」）· 2px accent 进度条 ·「68% · 剩余 4:12」· [暂停/继续] [停止]。点击 → 任务页 / compact 全屏 Sheet。完成后显示 5s「已完成 ✓」再收起。

### 2.6 Toast / 通知
- 位置：regular 右上（工具栏下 8px）；compact 顶部居中。最多 3 条，同 key 合并（×3）。
- 时长：信息 4s、成功 3s、警告 6s、**错误常驻**；悬停/聚焦暂停计时。
- 不用 toast：Alarm → 内容区顶部红色横幅；表单校验 → 字段内联；当前视图已可见的信息。
- 任务完成：toast + 可选浏览器 Notification + 提示音（`alertFileComplete`）。
- 破坏性操作（删除字体/项目/页面、覆盖 `$$`、停止任务、重启、恢复备份）用 Alert Dialog：标题陈述后果，危险按钮 red 文字、非默认焦点。可撤销的（删元素、删历史）不确认，改为 toast「撤销」5s / Mod+Z。
- WS 断开：内容区顶部黄色横幅「与设备的连接已断开，正在重连…」；机器控件禁用（急停除外，走 HTTP 重试）。

### 2.7 全局拖放导入
任何页面拖入文件 → 全屏半透明遮罩（`mat-thick`），按文件类型显示 1–3 个落点卡片：

| 类型 | 落点（默认高亮第一个） |
|---|---|
| .svg .dxf | 添加到当前页（矢量元素）· 新建项目 |
| .png .jpg .jpeg .webp | 添加到当前页（图片元素，可转路径）· 新建项目 |
| .gcode .nc .gco | 添加到当前页（G 代码元素，只读路径）· 直接发送到机器 |
| .txt | 添加为文本框 · 作为信笺正文 |
| .csv | 作为批量数据源（打开映射 Sheet） |
| .psf .gfont .ttf .otf .ttc | 安装到字库（TTF 系列打开转换 Sheet） |
| .penplot.json | 打开为项目 · 导入为模板 |

不在创作台时选「添加到当前页」会跳到最近项目。多文件一次拖入：逐个排列在页面中央并自动选中全部。不支持的类型：遮罩显示 orange「不支持 .xxx」。

#### 3.1.3 元素与操作
- **元素类型**：文本框（独立字体/混排/字号/对齐/抖动/种子，支持 `{{变量}}`）、图片（位图，渲染为路径后才可打印）、SVG/DXF 矢量（保留分组）、形状（矩形、圆/椭圆、直线、多边形、网格线/横线格——作业纸用）、G 代码（只读路径，可变换）、信笺正文框（仅信笺模式，唯一）。
- **变换**：选中显示 8 个方形手柄 8×8（触摸命中 44）+ 顶部旋转手柄 `rotate-cw`；Shift 等比/15° 步进，Alt 以中心缩放；箭头微移 0.1 mm，Shift+箭头 1 mm。
- **吸附与参考线**：吸附到纸张边缘/中线、边距线、其他元素边缘与中心、1 mm 网格（可关）；参考线 1px `--guide`（pink），显示间距标签（“12.0 mm”）；按住 Mod 暂时关闭吸附。
- **排列**：多选后对齐（左/中/右/上/中/下）与等距分布；成组/取消成组；层级（置顶/上移/下移/置底）；锁定（锁定元素不可选中拖动，图层列表中可点）；隐藏（不打印，画布 30% 显示）。
- **图层列表**：当前页元素按 z-order，拖拽排序，每行 [👁 可见] [🔒 锁定] 类型图标 名称（可重命名）；点选同步画布选中。
- **页面导航器**：缩略图（纸张比例）拖拽排序，右键/长按：复制、删除（确认）、插入空白页、应用其他纸张。信笺模式下页面由正文自动生成，缩略图带角标「自动」。
- **越界提示**：元素超出纸张 → orange 描边；超出机器行程 → 红色斜纹 + 检查器顶部警告；打印 Sheet 中阻止（可「仍要打印」）。

| 图片 | 转换（模式 [轮廓 edge｜中心线 skeleton｜点阵 dots]；edge：blur、th-low/high、simplify、min-len；skeleton：binarize、simplify、min-len；dots：spacing、gamma、power-modulate、dwell-max（仅激光 Profile）；通用：反相、max-px、[原图 ◀▶ 路径] 对比开关）· 排列 |

#### 3.1.5 原点、坐标轴与机器行程（画布可视化）
- 检查器「原点与坐标」：**四角选择器**（纸张缩略矩形，四角 + 中心 5 个热点，选中为 accent 实心圆）；交换 XY（`arrow-left-right`）；X 反向、Y 反向 开关；偏移 X / Y（mm，纸张左上相对机器原点的位置）；来源标签「来自 Profile grbl-zpen · 本项目已覆盖 ●」+ [恢复 Profile]。
- 画布叠层（工具栏「视图」菜单可逐项开关）：
  - **原点标记**：十字 + 圆 12px `--axis-origin`，旁标「原点 (0,0)」。
  - **坐标轴箭头**：自原点画 24mm 箭头，X 用 `--axis-x`（teal）、Y 用 `--axis-y`（purple），标注 +X/+Y；交换/反向时箭头即时翻转（220ms 过渡）——刻意避开 red/green 状态色。
  - **机器行程**：indigo 虚线矩形（`workArea` 尺寸）围住纸张，纸张按偏移放置；行程外区域斜纹；可在画布上直接拖动纸张调整偏移（吸附 1mm）。
  - **当前笔位置**（已连接时）：accent 实心点 + 外圈脉动（reduced-motion 时不脉动）。

## 5. 响应式、快捷键、无障碍

### 5.1 断点
| 名称 | 宽度 | 侧边栏 | 检查器 | 创作台左栏（页面/图层） | 导航 |
|---|---|---|---|---|---|
| compact | <768 | 无（标签栏 + 更多） | 底部 Sheet | 底部页面条 + 图层 Sheet | 导航栈 + 大标题 |
| medium | 768–1023 | 叠加滑出 | Popover 360 / Sheet | 可折叠浮动面板 | 工具栏 |
| regular | 1024–1279 | 默认隐藏、叠加滑出 | 固定 300 | 固定 200（可收起） | 工具栏 |
| wide | ≥1280 | 固定 240 | 固定 300 | 固定 200 | 工具栏 |

- 面板开合状态按断点分别记忆；横竖屏/缩放窗口不丢状态。iPad + 触控自动「舒适密度」。
- compact 键盘弹出时，底部条随 `visualViewport` 上移，标签栏隐藏；`env(safe-area-inset-*)` 用于标签栏、机器条、Sheet；禁止整页双击缩放，只在画布内 pinch。
- 画布：滚轮平移，Mod+滚轮/捏合缩放；触摸单指在空白处平移、在元素上拖动，双指缩放，双击空白切换 适合/100%。Apple Pencil/笔 = 选择与拖拽（不画）。
- 工具栏溢出：低优先级控件依次收入 `⋯` 菜单（顺序：记录切换 → 插入 → 走边框 → 预览），主操作与急停永不收起。

### 5.3 无障碍
- `<html lang="zh-CN">`；所有图标按钮有中文 `aria-label` + tooltip；画布叠层颜色同时配文字标签（+X/+Y、原点、行程尺寸）。
- 对比度：正文 ≥4.5:1，大字/图标/参考线 ≥3:1；`--on-tint-*` 用于着色背景上的文字。
- 焦点环 `outline:3px solid rgb(var(--accent)/.5); outline-offset:2px`（仅 `:focus-visible`）；Radix 负责焦点陷阱与归还。
- 触控目标 ≥44×44（变换手柄视觉 8px、命中 44）；危险与主操作间距 ≥8。
- 画布可键盘操作：Tab 在元素间循环（按 z-order），Enter 进入编辑，箭头微移，所有拖拽操作在检查器「排列」中有数值等价物；画布 `role="application"` + `aria-roledescription="排版画布"`，选中变化播报「已选中 文本框“正文”，X 31.8 Y 25.4 毫米」。
- 状态：颜色 + 图标 + 文字；进度条 `role=progressbar` + `aria-valuetext="42%，剩余约 13 分钟"`；胶囊 `aria-live=polite`（进度每 10% 播报），报警/急停 `assertive`；控制台 `role=log`。
- 支持 `prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-contrast:more`（separator alpha→.6、填充加 1px 描边）；浏览器缩放 200% 时降级到下一断点、不横向滚动。
- 表单：label 关联、错误 `aria-describedby`；每个滑块配数值框与单位（mm/°/%/mm·min⁻¹）。
