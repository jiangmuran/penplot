## Already done in the core (do not redo)
- Layout is cached per text → deterministic pages (01 §18 B1). `parse_gcode` handles Z pen / multi-G / G91 (B2).
- Sender: per-line RX accounting, error/ALARM handling, pen-up-before-home on stop, pause/resume, single-step.
- GRBL controller: `state`, `position`, `query_status()`, `wait_idle()`, ALARM event, jog fallback restores G90.
- Lazy `.gfont` ZIP decoding; `psf.font_index()`; CLI `print` auto-zero + SIGTERM = stop.
- Tests: `.venv/bin/python -m pytest -q` (≈75 s; needs `fonts/`). Keep them green.

## Hardware facts (never guess these)
GRBL 1.1f, CH340 `/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0`, 115200. Pen = Z stepper, **Z0 = pen up (rest), Z+8 = pen down**, zSpeed 5000, no dwell (`configs/grbl-zpen.json`). No homing/limits. Origin = pen position at job start, LeftUp corner, Y negative downward. Reference board: Orange Pi Zero 3 on the LAN (`<board-ip>`), ssh as root with a key, aarch64 py3.12, 2 GB RAM, WiFi; no Node/nginx. Other services may already run on the board — never touch what is not ours.

## Conventions
- Backend dev server: `PENPLOT_DEV=1 PENPLOT_DATA_DIR=~/.penplot-dev .venv/bin/python -m penplot.web serve` on :8080 with **FakeGrbl** when `PENPLOT_SERIAL_PORT=fake` (dev only). Frontend dev: `npm run dev` (Vite :5173, proxy `/api` + WS → :8080).
- API base `/api/v1`; cookie auth + header `X-Penplot: 1` on unsafe methods; errors `{"error":{"code","message","detail"}}`.
- Types: `webui/src/api/schema.d.ts` generated by `openapi-typescript` from `docs/design/openapi.json`.
- Stack (fixed): React 19 + TS + Vite, Tailwind v4 (`@tailwindcss/vite`), Radix primitives (shadcn-style components written in-repo), lucide-react, TanStack Query, Zustand, react-router v7. No other UI frameworks.
- Do not commit; the integrator commits. Do not deploy to the board or open the real serial port (the plotter may be in use); use FakeGrbl.
- Never write to the SD card at high rate; never log serial traffic to disk.
