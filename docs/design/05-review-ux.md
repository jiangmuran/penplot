## 0. 结论先行：十个最重要的修复

| # | P | 负责方 | 问题 → 修复 |
|---|---|---|---|
| 1 | P0 | shell | **页面一旦渲染出错，整个外壳都会被卸掉，急停按钮也跟着消失**。原因是 `router.tsx` 只在 `/` 根路由上挂了 `errorElement`，`review-se-machine.png`、`review-desk-focus.png` 里 `/machine` 因为 `(ports.data ?? []).map is not a function` 整页白屏。→ 给每个子路由各挂一个 `errorElement`（渲染在 `<Outlet/>` 里面），侧边栏、机器条、急停、迷你播放器必须一直留在屏幕上。另外，数组类接口的返回值统一先 `Array.isArray` 检查再用。 |
| 2 | P0 | shell | **急停浮层盖住了 Sheet 的关闭按钮和内容**：`pages-projects-batch-desktop-light.png` 右上角 ✕ 被急停按钮挡住；`pages-projects-batch-phone-light.png`、`i-more-phone.png` 里，底部 Sheet 的「预览」和「退出登录」行被挡住。→ 右侧 Sheet 顶部留出 `--toolbar-h` 的安全区（或者把 Sheet 头部右侧让出 96px）；compact 底部 Sheet 加 `padding-bottom: 72px + safe-area`。 |
| 3 | P0 | backend+shell | **「等待换纸」和「需要处理」时没有任何提醒**：`live-effects.tsx` 只处理 done/failed/aborted，没有声音，页面在前台时也不发通知，iOS Safari 又不支持 `Notification`。→ 新增 `paused(reason=paper_change|error|alarm)` 事件，触发提示音（Web Audio，第一次点击后解锁）、`navigator.vibrate`、标题闪烁「⏸ 请换纸 · PenPlot」，再加上 PWA manifest 和 iOS 主屏通知。 |
| 4 | P0 | shell+pages:settings | **没有首次上机向导**：管理员设好密码后直接进入占位的创作台。Z 校准、方向确认、原点、行程这些知识分散在 控制 / 设置 / 调试 三处。→ 做一个 5 步向导：连接 → 点动 +X/+Y 确认方向 → Z 落笔校准 → 移到纸张左上角并设原点 → 试画 10 mm 方块。可以从「系统」或空状态再次进入（详见 §1.1）。 |
| 5 | P0 | studio+backend | **打印前要能回答「放不放得下、要写多久、会不会写出界」**：打印 Sheet 里必须在 [开始打印] 旁边显示纸面和行程叠加图、预计时间和完成时刻、缺字数量；超出行程时阻止打印；走边框是推荐的一步（详见 §1.2）。 |
| 6 | P0 | pages:jobs | **失败或中断后的恢复路径不清楚**：任务详情的主按钮是「重新打印」，「从第 N 行续打」藏在下面，文案里还露出了 `409 origin_invalid`（`wip-jobs_h2-phone-dark.png`、`job-detail.tsx:233`）。→ 失败卡片按原因给出带下一步的操作（详见 §1.6），续打设为主操作，去掉文案里的 HTTP 码。 |
| 7 | P0 | shell | **手机上停止键、急停键和迷你播放器挤在一起**：`review-se-jobs.png` 里 ■ 停止和急停相距大约 16pt；在 /jobs 页面迷你条还和页面里的大按钮重复出现。→ compact 下 /jobs 隐藏机器条里的播放器；迷你条只保留 暂停/继续，「停止」只在任务页出现；急停和其他控件之间至少空出 16pt。 |
| 8 | P1 | pages:machine | **「断开」按钮放在手机导航栏最显眼的位置**（`wip-machine-phone-light.png`），而重新打开串口会复位主板、丢失坐标。→ 把它移进「更多」并加确认：「断开后再连接会复位控制板，需要重新设原点」。 |
| 9 | P1 | 全部 | **术语不统一，开发者用语直接露给用户**：零点/原点、Profile、DRO、Sheet、GFONT/PSF、DPI、栅格、掩码、`error:20`、空程。→ 按 §3.10 的术语表统一，再给关键术语加 ⓘ 解释。 |
| 10 | P1 | shell | **11px 的中文和 30% 透明度的 tertiary 灰字太多**，对比度约 2.3:1（时间戳、「此页面正在建设中」、字形码位、登录页「设备离线」）。→ 桌面端中文最小 12px；tertiary 只用于占位符和禁用态，说明文字一律用 secondary。 |

## 3. 建议新增的人性化功能

### 3.1 首次上机向导（P0 · shell+pages:machine）
见 §1.1。要点：每步都有插图和「我做不到」的帮助链接；向导结束时生成一张「本机名片」（行程、落笔深度、方向），放在设置里。

### 3.2 合理默认值与预设（P1）
- 纸张：最近用过的 3 种纸置顶；内置「明信片 148×100」「贺卡对折 A5」「DL 信封」「信纸 16 开」。（pages:settings）
- 字号默认 8 mm；行距按纸张自动算（信笺 = 版心高 / 行数，默认 A4 22 行）。（studio）
- 打印默认：开始前自动设原点「开」，**断线自动暂停「开」**，固件报错停止「开」。（backend）

### 3.3 撤销无处不在（P0 · 各处）
创作台用完整历史栈；删除项目、字体、历史、纸张预设先做软删除，toast 带 [撤销] 10s；设置的修改显示「已保存 · 撤销」；GRBL 写入之前自动备份 `$$`，并提供 [恢复写入前]。

### 3.4 术语的就地解释（P1 · shell 提供 `<Term>` 组件）
在原点、走边框、G 代码、落笔深度、空程、合并距离、软暂停、续打这些词旁边放 ⓘ Popover，一两句话加一张小图。例：
- **原点**：开始写字时笔所在的位置。写字机没有回零开关，所以每次开工前都要把笔停在纸张左上角。
- **走边框**：笔抬起，沿着要写的区域外框走一圈，用来确认纸放对了，不会写到纸外。
- **G 代码**：发给写字机的移动指令，一般不用管；导出后可以给别的写字机用。

### 3.5 打印前「放得下吗」和时间反馈（P0 · studio+backend）
见 §1.2-8。时间估算要标明来源（「根据你最近 5 次任务校准」），并用「预计 15:42 写完」的形式。

### 3.6 完成或需要处理时提醒（P0 · shell+backend）
- 事件：完成、等待换纸、暂停（出错）、报警、断线后自动暂停。
- 方式：提示音（三种音色区分完成 / 换纸 / 出错，设置里可选和试听）、浏览器通知、`vibrate`、标题闪烁、PWA 角标 `navigator.setAppBadge`。
- iOS：加 `manifest.webmanifest` 和 `apple-touch-icon`，在设置里引导「添加到主屏幕后才能收到通知」。目前 `index.html` 两者都没有。

### 3.7 最近使用与收藏（P1）
字体、纸张、手写预设、颜色、项目都记录最近 5 项；字体支持星标；创作台字体选择器顶部是「最近」。（studio+pages:fonts，后端存在用户偏好里，多台设备同步）

### 3.8 模板库内容（P1 · pages:projects+backend 内置）
「信笺（A4 竖，22 行）」「明信片正反面（地址格 + 邮编格）」「新年 / 生日 / 教师节贺卡（对折 A5，留白区）」「DL 信封 `{{收件人}}` `{{地址}}` 批量」「田字格 / 米字格练字纸（可选字帖文本）」「请柬」「签名 / 落款印章区」「感谢卡（小 148×100）」「作业纸横线」「便签 76×76」。每个模板带示例文字和推荐字体，卡片上显示「约 12 分钟」。

### 3.9 会教人的空状态（P1）
- 项目为空：「写第一封信」→ 打开书信模板，正文里预填一段示例。
- 任务为空：「还没写过东西。把纸放好、笔停在左上角，然后在创作台点打印」+ 插图。
- 机器未连接：列出可能原因（USB 没插好 / 写字机没开电 / 被别的程序占用），[重新扫描]。
- 字库为空或只有内置字体：「导入 .gfont/.psf，或者把电脑里的 TTF 转成单线字」。

### 3.10 错误信息模板与中文文案规范（P1 · 全部）
- 错误 = **发生了什么 + 为什么 + 怎么办（按钮）**，错误码放进「技术详情」。例：「写字机报警：没有回零就移动了（ALARM:9）」→「本机没有限位，这通常是因为 $22 被打开了。[去关闭 $22] [解锁]」。
- 术语表（只用左边的词）：**原点**（不用零点/零位，Z 轴说「抬笔位」）· **走边框** · **机器配置**（不写 Profile）· **位置**（不写 DRO）· **落笔深度** · **空走**（不用空程）· **续写**（不用续打，二选一后全局统一）· **字体文件**（不露出 GFONT/PSF）· **写字速度**（mm/分）。
- 语气：用「你」，句子短，不用「请您」堆砌；按钮用动词加宾语（「设为原点」「继续写下一张」）；数字和单位之间加窄空格（`8 mm`），中文里的英文两侧加空格；标点用全角，Kbd 和代码保留半角。
- 危险确认：标题陈述后果（「断开后坐标会丢失」），按钮写具体动作（「断开」），不用「确定」。

### 3.11 其他（P2）
- 「换一种写法」时并排比较 3 个 seed 的缩略图。（studio）
- 「写过的名单去重」：批量时提示「张三 10 月 27 日已经写过」。（backend）
- 任务完成后给出「这次实际用了 23 分钟，比预计快 2 分钟」，并展示时间校准系数的变化。（pages:jobs）
