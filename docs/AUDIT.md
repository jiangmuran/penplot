# 兼容性审计记录（核心库 penplot/）

> penplot 的写字排版和 G 代码输出以"与原软件输出一致"为目标（格式说明见 [ANALYSIS.md](ANALYSIS.md)）。
> 本文件记录历轮对照检查发现的行为差异、修复方式和已知边界。每一项修复都带数值测试
> （`tests/`、`tests/scripts/`），不接受"看起来对了"。
>
> 对照依据：同一文本、同一参数下原软件导出的 G 代码与 penplot 输出逐行比较，加上真机行为。
> 本项目不包含、也不分发原软件的任何代码。

## 一、方法

- 按模块（gfont 格式 / G 代码 / 几何 / 排版 / 导出管线 / 机器协议）逐项对照输出与行为，
  重点看坐标语义、单位换算、边界条件、状态机分支。
- 能在本机验证的项跑数值测试；只能在真机验证的项明确标注。
- 真机行为与推断冲突时，以**真机为准**并记录到差异表。

## 二、第一轮：排版与导出

| # | 差异 | 正确行为 | 不修的后果 | 状态 |
|---|---|---|---|---|
| 1 | 字符 advance 多算了 minX 偏移 | advance = bbox 宽 + max(0,minX) | 每字被拉宽，整行溢出 | 已修 |
| 2 | 特殊标点加宽只加了 widthAdd | `shift(-minX)+widthAdd` 整体计入 advance | "，.。" 后间距不对 | 已修 |
| 3 | 字符步进只算 adv+charSpace | adv + charSpace + randomSpace 抖动 | 行宽偏窄、行末位置不一致 | 已修 |
| 4 | 换行判断不含右缩进 | cursor + 字宽 + 前字空隙 > 行宽 | 段落右缩进时每行多放一个字 | 已修 |
| 5 | 行对齐宽度只算到最后字的 adv | 全部步进之和（含行尾 gap） | 居中/右对齐整体偏右半个字距 | 已修 |
| 6 | 缺分散对齐 | 支持 Disperse | 功能缺失 | 已修 |
| 7 | randomFirstPos 用成 ±v | 单侧 [0,v] | 每行整体偏移分布错误 | 已修 |
| 8 | 段落格式（首行缩进/悬挂/左右缩进）缺失 | 按段落设置 | 功能缺失 | 已修 |
| 9 | 换行后"首行"标记不翻转 | 只有段首行是首行 | 首行缩进应用到每一行 | 已修 |
| 10 | 导出无坐标轴映射 | 对调 XY / 反向 / 四象限原点 | 机器装反轴时图形镜像或偏移 | 已修 |
| 11 | EBB 导出没做坐标变换 | EBB 强制 revxy+xr+yr，(x,y)→(-y,w-x) | EBB 机器图形镜像 | 已修 |
| 12 | 机器事件回调是单一变量 | 多播注册 | 回调互相覆盖 → 死锁/失联 | 已修 |
| 13 | Marlin 重发用了未填充的队列 | 从发送历史重建 | 断线后无法恢复 | 已修 |
| 14 | 象限原点平移只处理左上 | 四象限 | 原点不在左上时输出全错 | 已修 |

## 三、第二轮：五模块对照

| 级别 | 问题 | 修复 |
|---|---|---|
| 高 | K_AT 文件头尾不符 | 头部清空；尾=抬笔+`G0 X290 F3000`+`G0 Y420 F8000`；笔 `E0.2/E6 F4000`；双延迟强制 0 |
| 高 | 旋转方向相反（=−θ） | 采用标准仿射约定（m01=−s, m10=+s） |
| 高 | 页面旋转 90/270 时未换宽高 | 旋后矩形 w/h 互换再做轴映射/EBB/象限 |
| 高 | 多页导出重叠 | 按页导出；CLI 多页一页一文件；预览页距=页高 |
| 中 | Marlin 头多一行笔命令 | 头 = startGcode+G21+G90+G92（无笔） |
| 中 | 写字导出应不排序 | CLI `write` 默认不优化，`--optimize` 开启 |
| 中 | space/tabWidthAdd 单位多乘 dpi | 原样 px 相加 |
| 中 | 蛇形行序 | 奇数行倒序出笔 |
| 中 | 多字体随机混排缺失 | `font_mix=[(font,weight)]` + 缺字自动替换 + `--font-mix` |
| 中 | EBB 浮点/取整 | 全链 float32 + floor(x+0.5)，文件与实时命令一致 |
| 中 | gfont 容错 | ZIP 单条目损坏只丢该字；负计数报错 |
| 低 | 笔 Z/E 值格式 | `Z2.0` 形式；K_AT 用字面量 |
| 低 | M280 空格 | `M280P0S50` |
| 低 | `-0.000` 被归一化 | 保留 |
| 低 | 激光点阵缺头部笔命令/每点 G4 | 头部含 M5；每点 S+G4P(on)/S0+G4P(off) |
| 低 | EBB 实时抬笔延时 | 实时命令两向均 toolOnDelay |
| 低 | \n/\f 行宽、分散对齐 | 统一步进；\f 占位后换页；分散对齐每字后均匀加隙 |
| 低 | 元数据中的补充平面字符 | writeUTF 代理对重组（emoji 不再变 U+FFFD） |

有意保留的差异：

- **超宽字符**：原软件会静默丢弃放不下的后续文本；penplot 将其单独成行（更安全）。
- **RDP**：使用经典点到线段距离的 RDP，容差语义可能差半个像素。
- **手写随机数**：使用 Python `random`，分布一致，但不是同一条随机序列（`--seed` 可固定）。

## 四、第三轮：TTF 单线字管线

外部评审用 scikit-image 复现骨架管线并实测（十/永/我/国 路径数为真实笔画数的 1.5–2.5 倍），
确认 5 个 bug + 6 项算法改进，全部修复（`tests/scripts/test_ttf2.py`）。

| # | 问题 | 修复 |
|---|---|---|
| 1 | 缺字渲染成 .notdef 方框入库 | fontTools cmap 预过滤（TTC 按 face 对准） |
| 2 | 空格与比例字宽丢失 | 字形增加 advance 字段（psf `adv=`）；无墨迹字符生成纯 advance 字形 |
| 3 | 默认字符集缺全角标点 | 加入 GB2312 符号区（，。、；：？！《》等） |
| 4 | i/j/:/! 的点丢失 | 按 8 连通墨迹块逐块兜底 |
| 5 | 超高字形被裁切 / face 静默替换 / 吞异常 | 画布按 bbox 扩边；face 打不开即报错；异常打日志 |

| 改进 | 实现 |
|---|---|
| 交叉点接笔 | 距离变换估笔宽 w → 毛刺阈值 1.2w → 交叉像素聚类 → 对冲角 ≥145° 判为一笔穿过 → 补桥 |
| 笔画定向排序 | 横左→右、竖上→下；行量化粗排 + 最近邻 |
| 阈值自适应 | 全部阈值由笔宽派生，随字号缩放 |
| 轮廓矢量化 | fontTools Pen 直接展平贝塞尔轮廓（含组件递归） |
| 细化 | scikit-image 优先，内置 Zhang-Suen 兜底 |
| makemeahanzi | graphics.txt → psf，真实笔画/笔顺/方向（Arphic PL，需自取数据） |

已知边界：横折/钩类 90° 折角会拆成两笔；"国"外框常接成一笔（少抬笔，有意如此）；
极扁平斜笔的方向可能按横处理。

## 五、真机前需关注

1. 新机器先用 `penplot tool` 或网页「控制」页逐项验证：连接横幅 → 抬/落笔 → 小距离点动 → 设原点。
2. K_AT 出纸/驻笔顺序（X290→Y420）需真机确认送纸方向。
3. EBB 若真机仍见 ±1 步差异，检查浮点求值顺序。
